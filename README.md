# Deep Space Explorer

![Deep Space Explorer](assets/thumbnail.jpg)

驾驶探索飞船穿越一座程序化生成的旋臂星系：跳跃到陌生恒星系，扫描未知行星，收集样本换取信用点，升级飞船，去往更远的深空。主线「银心信号」：收集 7 块先驱者留下的信号碎片，抵达银河中心，扫描那颗奇点。

纯前端项目（Three.js + 原生 ES Modules），无需构建。当前版本：**v0.7.0**

## 玩法

- **探索**：用曲速在恒星系之间跳跃；单星、双星、三星系统各有不同的轨道与光照；行星分岩石、气态、冰巨三类。出发星系是真实的太阳系，银河里还有一批真实存在的恒星系统（比邻星、TRAPPIST-1、Kepler-16 等），数据来自天文观测，界面上用「实测 / 推测 / 生成」标签区分；每局还会随机启用几类特殊现象（红矮星、红巨星、热木星、熔岩行星、海洋世界、超级地球、紧凑多行星、环双星）。
- **扫描与收藏**：瞄准行星按住扫描，获得信用点、燃料与经验，并收藏一张行星卡片（K 键查看，可按星系筛选）；同时采样资源进入货舱。也可以扫描星系的主恒星，按 P 拍摄星系全景图（收藏夹的「星系全景」标签）。
- **货舱与升级**：货舱（I 键）里的材料可以加注燃料、修补船体、作为升级材料，也可以出售换取信用点；信用点和材料用来升级飞船（U 键）。
- **信号**：星系里散布着补给、求救、遗迹、干扰四类信标，强度不同，走近才能识别；干扰信号是陷阱。
- **危险**：恒星耀斑与高温区（越近越危险）、小行星带、船体失效，越接近银心越危险；银心奇点还有引力潮汐，必须靠近才能扫描。
- **主线**：收集 7 块信号碎片，每块都指向下一个星系，最终前往银河中心。
- **知识库**：按 L 打开。第一次遇到的恒星类型、行星类别、双星三星、真实星系、小行星带、耀斑等，会弹出介绍并收进知识库，没遇到过的不显示。
- **新手教学**：按你的进度分阶段弹出，不用背操作。

## 本地运行

项目使用 ES Modules，**不能直接双击 `index.html` 打开**（浏览器会因跨域限制拒绝加载模块），需要用一个本地 HTTP 服务器：

```bash
# 任选其一
python3 -m http.server 8000
npx http-server -p 8000 -c-1
npm start            # 等同于 python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

> Three.js 通过 jsDelivr CDN 加载（见 `index.html` 里的 importmap），运行时需要联网。

## 部署到 GitHub Pages

1. 把整个文件夹推送到 GitHub 仓库。
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`。
3. 稍等片刻即可访问 `https://<用户名>.github.io/<仓库名>/`。
4. **分享预览图**：`index.html` 里的 `og:image` / `twitter:image` 目前是相对路径 `assets/thumbnail.jpg`，大多数社交平台要求**完整网址**。部署后请把这两处改成：
   `https://<用户名>.github.io/<仓库名>/assets/thumbnail.jpg`

## 存档与种子

- 进度保存在浏览器 `localStorage`（键 `deepspace-explorer-save-v1`），辉光偏好键为 `deepspace-bloom`，新手教学进度为 `deepspace-tut3`，已看过的知识介绍为 `deepspace-know`，知识库已解锁的条目为 `deepspace-lib`（及 `deepspace-libseen`）。
- 同一个种子永远生成同一个银河。默认种子 `42`，可用 URL 参数指定，例如 `?seed=1234`；开始界面的「新的银河」会随机换一个。
- 想重新看教学或知识介绍：在帮助面板点「重新开始教学」（不会清空知识库里已解锁的条目）。
- 测试用 URL 参数：`?kb=reset` 清空知识库，`?kb=all` 解锁全部条目。
- **注意**：0.4.0 起银河生成有变化，旧版本的存档会与新版不兼容，请开新游戏。0.7.0 又加入了真实星系，同一个种子的银河里部分星系的名字、恒星和行星会不同，旧存档建议开新游戏。
